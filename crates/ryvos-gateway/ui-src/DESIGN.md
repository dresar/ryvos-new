## Written 1-Line Purpose Log (R-31)
- Primary Blue Gradient: #2E56E0 to #2448CB to #1D3AA8 delivers clear visual hierarchy and meets WCAG 2.2 AA with a 5.96:1 contrast ratio against white text.
- Restrained Neumorphic Shadows: Dual soft shadows provide tactile elevation limited to 1 or 2 focal surfaces per view, with subtle shadows on interactive buttons and inset shadows for inputs.
- Data and Log Flat Surfaces: Heavy data tables, execution logs, and activity streams remain flat with 1px solid borders to maximize legibility and scanning speed.
- Glassmorphism Dose Cap: Translucent backdrop blur is strictly capped to two elements across the shell: the sticky top app header and modal backdrops.
- Focus Ring Glow: Keyboard navigation is indicated via a distinct 0 0 0 3px focus ring for all focusable elements without relying on mouse hover states.
- Structural Radius Hierarchy: Radius scales predictably from 8px for status tags, 12px for inputs, 14px for buttons, 18px for cards, 24px for focal panels, to 999px for pills.
- Semantic SVG Icons: Precise 24x24 rounded stroke SVG icons represent actions unambiguously without emojis or generic AI sparkle graphics.
